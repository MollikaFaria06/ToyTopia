# 🧸 ToyTopia – A Local Kids Toy Store Platform

## 🌈 Project Overview
**ToyTopia** is a vibrant and playful online marketplace for kids' toys, encouraging families to discover and support **local toy sellers**.  
Users can **log in, browse toys and view detailed information** for toys they want to buy for their kids.

Live URL:https://sprightly-gumdrop-14e1db.netlify.app/

---

## 🎯 Purpose
The goal of ToyTopia is to create a fun, safe, and engaging online platform where:
- Families can find quality toys from trusted local sellers.  
- Local toy businesses can reach a wider audience.  
- Kids can explore new toys that help them learn and grow creatively.

---

## ✨ Key Features

### 👶 User Experience
- Fully responsive UI built with **Tailwind CSS** and **DaisyUI**.  
- Interactive homepage with an image slider and featured sections.  
- Easy navigation through toys, events, and featured sellers.

### 🔐 Authentication
- Firebase Authentication for:
  - Email & Password Login  
  - Google Sign-in  
  - Password Reset Functionality  

### 🧮 Core Features
- Browse toys by category.
- View toy details (name, price, rating, and seller info).
- Add or manage toys (for authenticated users).
- See upcoming toy fairs and workshops.
- Display featured local toy sellers with ratings.

### 🌟 Additional
- Toast notifications for login/signup feedback.
- Smooth transitions and animations using AOS (Animate On Scroll).
- Context API for global user state management.
